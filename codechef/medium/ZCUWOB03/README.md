## Problem

### Printing Values Using a For Loop

In this example, we demonstrate how to use a for loop to print `"I love coding"` followed by numbers within a specified range. The loop iterates through the given range and appends each number efficiently.

 **When executed, the code will show:** 

```
I love coding 1  
I love coding 2  
I love coding 3  
I love coding 4  
I love coding 5  

```

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-17T10:35:55.085Z  

```java
class Codechef {
    public static void main(String[] args) {
        // Loop to print numbers from 1 to 5
        for (int i = 1; i <= 5; i++) {
            System.out.println("I love coding " + i); // Print statement with iteration value
        }
    }
}
```
